# 3-DOF-Robotic-Arm
This project demonstrates a 3 Degree of Freedom (3 DOF) Robotic Arm designed and controlled using an Arduino Uno. The arm uses four 180° servo motors to simulate human-like movements — base rotation, shoulder lift, elbow bend, and gripper control. Each servo is manually controlled by a 10kΩ potentiometer, allowing smooth and proportional motion.
